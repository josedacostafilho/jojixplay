# Static hand

Source: [WebXR Input Profiles, generic-hand/right.glb](https://github.com/immersive-web/webxr-input-profiles/blob/f4992299601614adbfefd398dc8e281556bb7444/packages/assets/profiles/generic-hand/right.glb), commit `f4992299601614adbfefd398dc8e281556bb7444`.

MIT, copyright 2019 Amazon; full notice in LICENSE.txt, bundled with the renderer. The unmodified source GLB is 94,004 bytes, 1,360 vertices and 2,314 triangles, with no textures. The renderer bakes its existing pose into one static mesh, aligns the palm, uses two colored materials and mirrors it for the other hand. No authored geometry or finger animation is added. All assets are served locally.
